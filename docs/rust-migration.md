# Rustへの移行

`replace-to-rust`ブランチで、アプリ本体とGUIをRustへ置き換えました。
Electron、React、TypeScript製のアプリコードとビルド工程は削除しています。
元の実装は移行前のコミット`7f09252950203f649754696604ad282dfdac76d7`から参照できます。

Neovim本体、Luaによる編集機能、言語サーバー、CodeLLDBは引き続き外部ツールです。
Node.jsは同梱TypeScript言語サーバー用で、GUIの実行には使いません。

## 構成

| 担当 | 実装 |
| --- | --- |
| ネイティブウィンドウ、各パネル、入力、IME、クリップボード | `src/app.rs`、eframe / egui / AccessKit |
| Neovimのセル描画、ハイライト、カーソル、補完、Sticky Scroll | `src/grid.rs`、OpenGL |
| ワークスペース、ターミナル、MessagePack-RPC | `src/backend.rs`、`src/rpc.rs` |
| エクスプローラー、監視、検索、一括置換、Git | `src/files.rs`、`src/git.rs`、notify |
| 設定、復元、お気に入り、Time Machine、拡張 | `src/settings.rs`、`src/persistence.rs`、`src/history.rs`、`src/packs.rs` |
| WSL接続、Windows外観、アップデーター | `src/wsl.rs`、`src/platform.rs`、`src/updater.rs` |

上段のワークスペースは独立したNeovimプロセス、内側のファイルタブは各プロセスの
バッファという構成を維持しています。ファイル走査・全文検索・Gitは別ワーカーで処理します。
ファイル検索の応答には世代番号、置換と履歴復元には検証トークンを使います。

移植範囲には、エディター、ターミナル、コマンドパレット、エクスプローラー、
検索と置換、Git、補完・診断・参照・シンボル、デバッガー、言語パック、設定、
お気に入り、復元、Time Machine、Markdownプレビュー、更新確認を含みます。
GUIはeguiで描き直しており、以前のCSSによる外観との完全一致は目標にしていません。

## 既存データ

保存先は従来どおり`%APPDATA%/nido`です。`NIDO_DATA_DIR`で分離できます。
バージョン1のワークスペースJSON、履歴、言語パックを読み込みます。
旧Electronの設定はLocal StorageのLevelDBを一時コピーして取り込み、元のDBは変更しません。

破損した設定・お気に入り・ワークスペース・履歴を空データで上書きしないようにしています。
履歴保存の失敗は通知しますが、通常のファイル保存を妨げません。
一括置換は変更前のディスク内容とバッファ状態を照合し、未保存の変更がある対象を拒否します。
適用と履歴復元は未保存の編集として行い、Undoできます。
終了や更新前には未保存バッファを確認します。

## ビルドと配布

Windows x64向けです。開発手順はルートのREADMEを参照してください。
現在のローカル検証環境はRust 1.99.1です。Cargoの最低バージョン指定は1.95で、
1.95そのものを使ったビルドは未実施です。

`scripts/prepare-runtime.ps1`が固定バージョンのNeovim、Node、TypeScript LSP、
CodeLLDBを準備します。取得アーカイブはSHA-256を照合します。
`scripts/package-windows.ps1`がCRTを静的リンクしたリリース実行ファイル、
NSISインストーラー、ポータブルZIP、チェックサム、旧クライアント向け`latest.yml`を生成します。
NeovimとCodeLLDBが必要とするVC++ランタイムDLLも、それぞれの実行ファイルの隣へ同梱します。

インストーラーは以前と同じアプリのインストール先・アンインストール登録を使います。
起動中の実行ファイルを上書きせず、旧Electronの既知の配布ファイルを取り除きます。
ユーザーデータはインストール先の外に保ちます。
パッケージ検証には`/NOINTEGRATION`と専用フォルダーを使い、実際の利用環境へ登録しません。

Windows CIはfmt、Clippy、単体・統合テスト、配布物生成、インストール後の統合テストを実行し、
検証対象のコミットIDと配布物を保存します。タグのリリース工程は同一コミットの成功したmain CIを要求します。
この作業ではコミット・push・リリースを実行していないため、リモートCIの成否は未確認です。
公開時には既存リリースより新しいCargoバージョンへ更新してください。

## 検証

ローカルで使うコマンド:

```powershell
cargo fmt --all -- --check
cargo clippy --locked --all-targets -- -D warnings
cargo test --locked
cargo run --locked -- --smoke-test
./scripts/package-windows.ps1
./scripts/test-package.ps1
```

単体テストはパス境界、検索・置換、RPCの型、設定取り込み、保存データ、
履歴の整合性、言語パック、グリッド、WSLパス、更新URLの検証を対象にしています。
統合テストは一時ワークスペースで以下を検証します。

- 実NeovimのUnicode編集・保存、入力待ちコマンド、CRLF置換、未保存保護、復元、履歴。
- Gitの未追跡ファイル、最初のコミット前のステージ操作、コミット、ブランチ、履歴。
- ターミナルの入出力、再起動、終了。
- eguiの描画、IMEイベントの確定と保存、順序付きパレット入力、古い応答の排除。
- ファイル操作先の固定、ペアターミナルのフォーカスと再作成、終了確認とキャンセル。
- 同梱TypeScript LSPの診断、自動補完の表示・確定、ドキュメントシンボル。
- 同梱CodeLLDBによるRustのビルド、ブレークポイント、変数、ステップ実行と続行。

`test-package.ps1`は新規インストール、旧Electron配布物を模した上書き更新、
インストール済み実行ファイルでの統合テスト、無関係のファイルを残すアンインストールを検証します。

2026-10-28のローカル結果: fmt、Clippy、単体テスト13件、上記の全統合テスト、
最終インストーラーでの導入・上書き更新・統合テスト・アンインストールは成功しました。
ワークフローはactionlint、PowerShellスクリプトは構文解析も通過しています。
アンインストール検証はWindowsによる終了後の実行ファイル解放を待ってから実行します。
最終配布物は`dist/release/nido-0.4.0-setup.exe`と`nido-0.4.0-windows-x64.zip`です。

実ウィンドウの起動、基本入力、エクスプローラーの操作は確認しています。
その後、ユーザーのEscape操作でUI自動操作を停止しました。
合成IMEイベントの成功と、物理キーボード・日本語IMEの実機確認は別の証拠として扱います。

## 残る制約と手動確認

- 日本語IMEの実機入力、複数DPI・モニター、長時間利用と性能の比較測定は未確認です。
- WSLは接続コードとパス検証を移植していますが、実ディストリビューションへの接続は未確認です。
- Markdownはネイティブの簡易プレビューです。画像・HTMLは旧版同様に描画せず、表・文字装飾の表示は簡略化しています。
- 更新は手動確認から開始します。公開サーバーからの実ダウンロードと、利用中の旧版からの更新は未確認です。
- macOS・Linuxのアプリ配布、旧Playwrightテストの再実行は対象外です。入力・描画の回帰確認はRust側へ移しています。

過去のElectron向け調査資料については[ドキュメント一覧](README.md)を参照してください。
