# ウィンドウのキーボード操作

エディターのNormalモードで、Spaceを押してから次のキーを押します。Spaceで表示される案内からも操作を確認できます。

| キー      | 操作                                 |
| --------- | ------------------------------------ |
| `Space -` | ウィンドウを最小化                   |
| `Space +` | ウィンドウを最大化・元のサイズに戻す |
| `Space q` | Nidoを終了                           |

`+`はプラス記号を入力するキーの組み合わせです。Insertモードでは、Spaceやこれらの記号は通常どおり入力されます。

`Ctrl+Shift+P`で開くコマンドパレットからも同じ操作を選べます。ワークスペースを開く前や、ターミナルから操作するときにも使えます。

終了時に未保存の変更がある場合は「すべて保存」「キャンセル」「変更を破棄」を選ぶ確認が表示されます。キャンセルすると編集に戻れます。

最小化したウィンドウへは、Windowsの`Alt+Tab`などで戻れます。

設定の「コンパクトモード」を有効にすると、すべてのセッションタブを表示したまま、セッションタブ・ファイルタブ・ステータスバーを低く表示します。マウスを重ねても高さは変わりません。`Alt+Shift+W`でセッションタブに移動し、`Esc`でエディターに戻れます。

ファイルタブはドラッグで並び替えられます。`Ctrl+Shift+PageUp` / `Ctrl+Shift+PageDown`で現在のファイルタブを左右へ移動でき、通常のファイル切り替えもこの順序に従います。

`Ctrl+Shift+T`で、この起動中に閉じた直近100件の名前付きファイルを新しい順に開き直し、カーソル位置とタブの位置を復元します。破棄した未保存の編集は復元しません。コマンドパレットからも移動と開き直しを実行できます。
